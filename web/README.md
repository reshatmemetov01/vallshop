# VallShop — публичный сайт (отдельный сервис)

Отдельный от Telegram-бота сервис: свой образ, свой контейнер, свой деплой.
Переиспользует бизнес-логику бота (`bot/services/*`, `bot/db/*`) и **общую БД**,
поэтому сайт и бот ведут себя одинаково, а новые типы товаров/поставщиков
подхватываются автоматически.

## Структура
```
web/
  app/
    main.py            # точка входа FastAPI (+ /healthz)
    config.py          # настройки из окружения (БД, наценка, база URL, позже JWT/SMTP)
    db.py              # подключение к общей БД (движок бота)
    routers/
      catalog.py       # API каталога (чтение): товары, номиналы, цены, наличие
  tests/               # смоук-тесты API
  requirements.txt
  Dockerfile
docker-compose.web.yml # отдельный деплой сайта
```

## Запуск (сервер)
```bash
# отдельно от бота:
docker compose -f docker-compose.web.yml up -d --build
# API: http://127.0.0.1:8090 (nginx проксирует домен сайта сюда)
# проверка: curl http://127.0.0.1:8090/healthz
```

## Локально (dev)
```bash
pip install -r web/requirements.txt
DATABASE_URL="sqlite+aiosqlite:///vallshop.db" uvicorn web.app.main:app --reload --port 8090
# тесты: pytest web/tests
```

## БД
На старте делит тот же SQLite-том с ботом (`./data`). Для продакшена
рекомендуется **Postgres** (общий для бота и сайта) — тогда оба сервиса
указывают `DATABASE_URL` на postgres (заготовка есть в `docker-compose.yml`).
Два процесса на один SQLite работают только при низком трафике (WAL).

## Готово (Phase 0 — каркас)
- Сервис FastAPI, отдельный образ/compose, подключение к общей БД.
- API каталога: `GET /api/catalog[?parent_id=]`, `GET /api/catalog/{id}`
  (категории/номиналы, цены как в боте, наличие; SMM — цена за 1000).

## Дальше (роадмап)
- Phase 1 — аккаунты: регистрация/вход (email+пароль), сессии/JWT, подтверждение
  почты+сброс (SMTP), вход через Telegram (Login Widget) + связывание/слияние
  кошелька с ботом.
- Phase 2 — фронтенд витрины (шаблон) + живое наличие у поставщиков.
- Phase 3 — пополнение баланса (провайдеры + существующие вебхуки).
- Phase 4 — покупки (чекаут + формы под все типы, выдача).
- Phase 5 — кабинет (мои заказы/история/VPN/отзывы).
- Phase 6 — рефералы/бонусы. Phase 7 — безопасность/QA/деплой.
